# Smart Dashboard usability notes

The V1.7 dashboard is intentionally opinionated about presentation:

- one primary theoretical edge is shown first;
- no pick is shown when nothing qualifies;
- complex probability diagnostics remain in specialist tabs;
- plain-English explanations use probability and break-even comparisons rather than unexplained model jargon;
- contextual inputs can nudge but not rescue a negative independent-market edge;
- Dutch opportunities are surfaced separately because full-market arbitrage and partial Dutch risk are different from a single-outcome EV estimate.

This file is a small implementation note rather than a separate model specification. See `MODEL_V1_7.md` for the probability/recommendation rules.
